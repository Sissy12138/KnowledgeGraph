# 研知图 0.3.0 使用说明

## 1. 启动应用

1. 解压后保持整个文件夹完整，不要只移动 `研知图.exe`。
2. 双击 `研知图.exe`。`resources`、`locales`、DLL 和内置 Python 运行时都是必需文件。
3. “空白应用版”不包含论文、分析任务、审核历史或图谱数据；“完整留档版”保留本次验证数据，适合备份和复核。

## 2. 连接 Zotero 并导入

1. 启动 Zotero，并确保本地 API 可用。
2. 在左侧进入“Zotero 同步”，选择整个文库或指定文件夹。
3. 先查看预览，确认论文数、重复提示和 PDF 状态，再执行导入。
4. 可分多次导入不同文件夹。在“知识图谱”顶部用“📁 文献范围”选择单个文件夹或“全部文件夹”。

## 3. 配置模型

1. 进入“模型配置”，选择服务商和模型，填写自己的 API Key。
2. 使用中转或其他 OpenAI 兼容服务时，选择自定义配置，填写基础地址和准确模型名。
3. 先保存，再测试连接。分析前系统会再次检查配置，未配置时不会创建空任务。
4. Windows 桌面版的 Key 使用当前用户 DPAPI 加密保存。分享程序时不要另外复制自己的模型配置文件。
5. 论文文本会发送到你选择的模型服务商，请先确认数据使用权限与服务条款。

## 4. 分析新导入论文

1. 在“文献库”点击“一键分析新导入文献”，或在论文详情中开始单篇分析。
2. 到“分析任务”查看进度。概念和方法会扫描全文高信号区域并分批处理；长论文在 55%–70% 附近停留较久可能是正在进行多批模型请求，请结合具体阶段文字判断。
3. 每篇论文最终最多保留 6 个核心概念和 6 个核心方法。这是全文召回、复核和去重后的结果上限，不是阅读范围上限。
4. 分析成功后，论文详情会显示研究主题、研究问题、样本及分组、方法、主要结果、主要发现和原文证据。“本轮分析未定位到明确原文证据”不表示原文一定没有该信息。

## 5. 重新分析已完成论文

在论文详情或“分析任务”中选择：

- **保留旧结果再分析**：适合比较不同模型或提示词的结果。旧数据保留，旧待审核建议转为历史状态。
- **用新结果替换**：适合确定旧结果噪声较大或分析规则已更新的情况。只有新分析完整成功后才删除该论文的旧提取、旧审核结果和旧图谱贡献；失败或取消不会破坏旧数据。

请在点击前核对按钮说明。“替换”会保留分析任务日志作为操作历史，但旧提取与旧审核内容不再作为当前数据。

## 6. 审核建议

1. 进入“建议审核”，先核对概念和方法的名称边界、中英文对应和原文证据。
2. 新增关系卡片会显示起点、终点、关系类型和双方名称。共现或同时出现不等于必然存在语义关系。
3. 拒绝一个概念或方法后，依赖它的关系会自动拒绝，无需逐条清理。
4. 已采纳内容可重新加入待审核，或改为拒绝。`cites` 引用关系不需审核。

## 7. 使用知识图谱

1. 在顶部切换“概念关系”“方法网络”“作者合作”和“文献引用”。
2. 使用“🔍 搜索节点”定位当前网络中的概念、方法、作者或论文。
3. 选中节点后，可用“显示相关作者/方法/概念”展开证据语境。无对应已审核数据时，开关不会人为生成连线。
4. 作者网默认突出第一作者、共同第一作者和通讯作者，并补充能够连接多个核心作者或具有重复强合作的桥接作者。一篇论文的全部作者不会被自动定义为一个团队。
5. “中文 / English”只切换图谱节点和关系的显示语言，不修改数据。英文原名缺失时会保留已有名称。

## 8. 常见问题

- **进度长时间停在 55%–70%**：先看阶段文字是否仍在分批增加。若长时间不变，检查模型连接、余额、限流和网络；失败任务可从任务页重新执行。
- **图谱没有新节点**：分析结果先进入建议审核，未采纳的概念、方法和语义关系不会当作正式图谱数据。
- **文件夹筛选后节点较少**：只显示所选 Zotero 文件夹涉及的论文及其关联数据；切回“全部文件夹”即可查看全库。
- **PDF 无法分析**：检查 Zotero 附件路径和文件是否存在。扫描件、加密文件或复杂排版可能需要 OCR 或重新获取原版 PDF。

## 9. 数据与隐私提醒

- 数据库包含文献元数据、分析记录、审核结果和图谱。分享“完整留档版”前应检查论文版权和数据授权。
- 不要把 API Key、个人 Zotero 数据目录或其他凭据放入交付包。
- 如需全新开始，使用“空白应用版”；如需复核本次测试过程，使用“完整留档版”的副本。
