# 研知图 0.4.0 更新日志

发布日期：2026-09-29

## 本次发布

- 统一桌面应用、页面标识、源码、文档和交付文件的版本号为 0.4.0。
- 提供 macOS Apple Silicon 空白数据版 DMG、ZIP 和 Windows x64 空白数据便携 ZIP。
- 空白版从 0 篇文献开始，使用独立的 `data-blank-v0.4.0` 本机数据目录。
- 随附源码、使用说明和 SHA-256 校验文件；不附带 API Key 或真实文献数据库。

## 主要能力

- Zotero 只读导入与文件夹范围筛选。
- 全文分批分析、概念与方法名称复核、关系二次判断。
- 概念、方法、作者合作和文献引用四种图谱视角。
- 人工审核、任务重新分析和本地知识问答。

## 已知限制

- macOS 包未经过 Apple Developer 公证；首次打开可能需要右键选择“打开”。
- Windows 包未签名，可能触发 SmartScreen；正式使用前建议在 Windows 10/11 上验收。
- 模型提取与问答结果需要结合原文证据进行人工核对。

详细操作见 [0.4.0 使用说明](使用说明-0.4.0.md)。
