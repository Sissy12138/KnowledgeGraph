# 研知图概念关系图上下文图层设计

## 目标

修正概念图节点颜色与图例颜色不一致、图例包含不可见“发现”等问题；选中概念后突出该概念及其一阶概念邻居，并允许通过画布左下角开关按需展示相关作者和相关方法。

## 数据边界

- `GraphDataset.nodes/edges` 继续表示当前网络的主图。
- 新增 `contextOverlay.nodes/edges`，只保存可选上下文节点及“经论文关联”的派生展示边。
- 派生边类型为 `conceptAuthor` 和 `conceptMethod`，必须携带 `sourcePaperIds`。
- 派生边不写回正式知识图谱，不进入建议审核。
- 作者上下文使用稳定作者节点 ID 与论文交集构造；在 A 提供正式 `author_id` 前仅作为明确标注的 Mock，不使用姓名匹配。

## 交互

- 概念图默认仅显示概念主图。
- 选中概念后，选中节点与一阶概念邻居保持完全不透明；其他概念节点降至 `0.18`。
- 画布左下角显示两个小型开关：`显示相关作者`、`显示相关方法`，使用 `aria-pressed`。
- 开启开关后，仅加入当前焦点概念通过论文关联的对应上下文节点和虚线派生边。
- 两个开关可独立或同时开启；离开概念视图时隐藏，返回时保留本页面会话状态。
- 点击上下文作者或方法可查看详情，概念焦点仍保持在最近选中的概念；选择新概念时替换上下文。
- 清空选择或重置时清除概念焦点，上下文节点消失；开关状态保留。

## 图例与视觉编码

- 节点和图例共享单一颜色表。
- 图例只包含当前实际可见的节点类型。
- 概念图默认图例只有“概念”；开启上下文后动态增加“作者”和/或“方法”。
- 概念—作者、概念—方法边使用虚线，标签分别为“相关作者”“相关方法”。
- 概念焦点存在时，非焦点主图边降低透明度，焦点相关边保持清晰。
- 搜索激活时沿用搜索淡化语义；搜索仅针对主图节点，不搜索隐藏上下文节点。

## 可访问性

- 上下文控件是独立命名区域。
- 按钮具有 `aria-pressed`，文本直接说明显示内容。
- 画布可访问名称中的节点数和关系数反映当前实际显示集合。

## 验收标准

- 概念节点颜色与“概念”图例颜色相同。
- 默认概念图例不含论文、作者、方法或发现。
- 选中概念时一阶概念邻居保持不透明，其余概念淡化。
- 作者/方法开关只显示当前焦点概念的相关节点与派生边。
- 同时开启两项时两类上下文均显示；关闭后立即移除。
- 切换概念后上下文随焦点更新。
- 其他三个网络行为不回归。
