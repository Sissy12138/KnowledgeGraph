# Windows 空白便携版构建说明

当前 Windows x64 空白包以此前的 Windows Electron 便携运行时为基础，更新了 0.3.1 前端、后端和分析流水线。该便携包必须保留整个目录，不能只移动 `研知图.exe`。

在 Windows 入口文件中，空白版使用独立端口 `17841`、`18042`、`8766`，用户数据写入 `data-blank-v0.3.1`。内置数据库只包含表结构，论文、图谱节点和分析任务初始数量均为 0。模型配置文件同样保存在空白版的独立用户数据目录中。

在 macOS 上已校验 PE32+ x64 文件、内置 Python x64、应用资源、SQLite 空库和 ZIP 完整性。Windows 程序不能在本机直接运行，仍需在 Windows 10/11 真机检查启动、Zotero 接入和模型连接。
