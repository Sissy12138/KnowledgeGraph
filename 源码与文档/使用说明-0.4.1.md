# 研知图 0.3.1 使用说明

## 1. 安装

macOS：打开空白数据版 DMG，将“研知图-空白版”拖入 Applications。首次启动若被拦截，请在 Finder 中右键应用并选择“打开”。当前包适用于 Apple Silicon。

Windows：解压便携版 ZIP 后双击 `研知图.exe`。请勿只移动 EXE，`resources`、`locales` 和 DLL 都是运行所需内容。

## 2. 配置模型

打开“模型配置”，选择服务商与模型，填写自己的 API Key，保存后点击“测试连接”。API Key 不包含在发布包中。

## 3. 导入与分析

1. 在“Zotero 同步”选择文件夹，先预览再导入；研知图不会修改 Zotero 原始条目。
2. 在文献库点击“分析新导入文献”。
3. 在分析任务页查看进度、取消或重新执行任务。
4. 已完成论文重新分析时，当前默认删除旧分析结果并使用新结果。

## 4. 审核与图谱

- 概念、方法、发现和非引用关系经用户审核后进入正式图谱。
- 拒绝概念或方法时，其依赖关系会自动拒绝。
- 已采纳内容可以重新打开或改为拒绝；`cites` 引用关系不进入审核队列。
- 图谱支持概念、方法、作者合作、文献引用四种视角和 Zotero 文件夹筛选。

## 5. 知识问答

1. 确认已有论文完成分析且模型连接成功。
2. 打开“知识问答”，输入问题或使用快捷问题。
3. 根据回答中的 `[1]`、`[2]` 查看参考材料。
4. 点击材料进入论文详情核对原文。

知识问答只读取本地知识库，不会自动改变图谱或审核状态。

## 6. 数据版本

- macOS 和 Windows 空白数据版都从 0 篇文献、0 个图谱节点开始，适合建立新的文献库。
- 空白版使用独立的本机数据目录，不会从已有完整数据版自动加载论文。
- 再次安装同一空白版会继续使用该空白版之后导入的本机数据；重要数据库仍建议定期备份。
